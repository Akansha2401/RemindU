# RemindU

## Firstly

For development we are using **Bun** for the development, **Not NodeJS**. <br>
As bun is faster and reduce the project's installation and package time reduces.

> For installing the bun please go to this link and install according to your Operating System. <br>
> [Bun installation link](https://bun.com/docs/installation)

> For project Initalization

```shell
bun install
```

> For Installing any packages user bun with below example

```shell
bun add <package-name-here>
```

### And while using claude code for development make sure to install Expo Claude code Plugin.

> Install the below plugin for claude to get access to expo's offical docs.

```shell
claude plugin install expo@claude-plugins-official
```
